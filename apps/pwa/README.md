# apps/pwa

Espace reserve a **psd2plpG** (PWA Cloudflare Pages + APK Capacitor).

## Statut

Non migre. Le projet source vit dans `Lemuelnk/Psd2plpG` (prive).

## Consommation du moteur

`psd2plpG` est une reimplementation TypeScript du moteur (parsing PSD,
SVG, ecriture PLP en JS pur pour fonctionner dans le navigateur).
Il ne consomme pas le package Python.

## Pourquoi migrer

- Une seule source de verite pour le format PLP
- Beneficier des fixes du moteur Python
- Documentation unifiee
